# 사람에게서 작업을 받았을 때

요청하는 사람은 **테니스장을 운영하는 분**입니다. 코드는 보지 않습니다.
대신 **무엇이 옳은 서비스인지는 그분이 정합니다.**

여기서 선을 하나만 기억하세요.

> **기술은 에이전트가 정합니다. 제품은 사람이 정합니다.**

폴더를 어디로 할지 물으면 요청자는 답할 수 없습니다.
환불을 며칠까지 허용할지 혼자 정하면 **실제 돈이 잘못 나갑니다.**

---

## 받으면 이 순서로

1. **어느 앱, 어느 화면인지 먼저 좁힙니다.** 안 적혀 있으면 물어보기 전에
   [직접 열어봅니다](verification.md#브라우저로-확인).
2. **재현합니다.** 재현되면 더 물을 것이 없습니다.
3. 재현이 안 될 때만 되묻습니다 (아래 [되묻는 법](#되물어야-할-때는-화면의-말로만)).
4. 고칩니다. 기술 선택은 [혼자 정합니다](#혼자-정하세요-묻지-마세요).
5. 제품 판단이 필요한 지점이 나오면 [그때 묻습니다](#반드시-물으세요-혼자-정하지-마세요).
6. `./scripts/verify.sh` + 브라우저.
7. [화면의 말로 보고합니다](#보고는-화면의-말로).

**"안 돼요" 한 줄짜리 신고가 대부분입니다.** 그건 정보가 부족한 게 아니라
**원래 그렇게 옵니다.** 되묻기 전에 먼저 열어보세요.

---

## 혼자 정하세요 (묻지 마세요)

이미 저장소에 답이 있는 것들입니다. **물으면 요청자를 막히게 할 뿐입니다.**

| 정할 것 | 답이 어디 있나 |
|---|---|
| 어느 폴더·파일에 넣을지 | [structure.md](structure.md) — 이름이 아니라 동작으로 |
| 파일을 새로 만들지, 기존 것에 넣을지 | [structure.md](structure.md#새-파일을-만들면-등록할-곳) |
| 함수·변수 이름 | [AGENTS.md](../AGENTS.md#코드-규칙) |
| 라이브러리를 쓸지 | **안 씁니다** ([AGENTS.md](../AGENTS.md#하지-말-것)) |
| 커밋을 몇 개로 나눌지 | [AGENTS.md](../AGENTS.md#커밋) |
| 버전을 올릴지, 어떻게 올릴지 | [releasing.md](releasing.md) |
| 검사를 추가할지 | 검사기가 놓친 사고가 났으면 **추가합니다** |
| 구현 방식·성능 | 알아서. 주변 코드와 같은 방식으로 |

## 반드시 물으세요 (혼자 정하지 마세요)

**되돌릴 수 없거나, 돈이 오가거나, 사용자 눈에 보이는 것**입니다.
요청자는 이걸 결정할 수 있는 사람이므로 물으면 바로 답이 옵니다.

| 물을 것 | 예 |
|---|---|
| 돈 규칙 | 환불 기한, 위약금, 이용권 몇 회 차감 |
| 누가 할 수 있나 | 코치가 남의 수업을 고칠 수 있나 |
| 화면에 나가는 문구 | 실제 문장 그대로 받으세요 |
| 이미 있는 데이터를 건드리는 것 | 기존 회원 이용권 일괄 변경 |
| 되돌릴 수 없는 것 | 배포, 삭제 |
| 요청이 두 가지로 읽힐 때 | 어느 쪽인지 |

⚠ **애매하면 묻는 쪽입니다.** 잘못 정한 정책은 검사기도 브라우저도 안 잡습니다.

### 되물어야 할 때는 화면의 말로만

질문에 **파일 이름·함수 이름·DB 컬럼 이름을 넣지 마세요.** 답할 수 없습니다.

```
✗ remaining 이 NULL 일 때 0 으로 볼까요?
✗ domain/tickets.js 에 넣을까요 새 파일을 만들까요?

✓ 잔여 횟수가 비어 있는 회원이 3명 있습니다.
  이분들을 "아직 안 쓴 것" 으로 볼까요, "다 쓴 것" 으로 볼까요?
  (추천: 아직 안 쓴 것. 지금 예약이 막혀 있습니다)
```

**한 번에 하나씩. 선택지를 주고. 추천을 붙이세요.**
"네/아니오" 나 "1번" 으로 답할 수 있어야 합니다.

## 운영 중에 급한 것

"지금 결제가 안 돼요" 처럼 서비스가 멈춘 요청입니다.

1. **정말 멈췄는지 브라우저로 확인**합니다. 한 사람만 그런 것일 수 있습니다.
2. **최근 배포가 원인인지 봅니다.** `git log --oneline -10`
3. **되돌리기가 고치기보다 빠르면 되돌립니다.**
4. **배포는 사람이 누릅니다.** `main` 은 푸시가 곧 실서비스입니다
   ([releasing.md](releasing.md)).

⚠ **급할수록 정리·리팩터링을 같이 하지 마세요.** 무엇이 고쳤고 무엇이 깨뜨렸는지
분간이 안 됩니다 ([AGENTS.md](../AGENTS.md#3-정리와-수정을-같은-커밋에-섞지-마세요)).

## 요청에 없는 것은 하지 마세요

- 부탁받지 않은 정리·이름 바꾸기·리팩터링을 끼워 넣지 마세요.
- "보이는 김에" 고치고 싶은 것은 [unfinished.md](unfinished.md) 에 적으세요.
- 요청을 임의로 **좁히지도 넓히지도** 마세요. 못 하는 부분이 있으면
  나머지를 다 끝내고 **못 한 것을 말하세요.**

## 보고는 화면의 말로

요청자는 코드를 볼 수 없습니다. **파일 이름을 적으면 확인할 방법이 없습니다.**

```
✗ domain/tickets.js 의 ticketState 를 수정했습니다.

✓ 잔여 0회인 이용권이 "사용 중" 으로 보이던 것을 "소진" 으로 고쳤습니다.
  관리자 > 회원 상세에서 직접 눌러 확인했습니다.
  회원앱에도 같은 표시가 있는데 거기는 확인하지 못했습니다.
  아직 배포 전이라 실제 화면에는 반영되지 않았습니다.
```

네 가지를 꼭 넣으세요.

1. **무엇이 달라졌는지** — 화면에서 보이는 변화로
2. **어떻게 확인했는지** — 어느 화면에서 무엇을 눌렀는지
3. **확인하지 못한 것** — 제일 중요합니다. 빠뜨리면 확인한 것처럼 읽힙니다
4. **배포해야 보이는지**

## 요청자에게 그대로 전달할 안내

아래를 복사해서 요청하는 분께 주세요.

> **작업을 부탁하실 때 세 가지만 적어주시면 됩니다.**
>
> 1. **어디서** — 회원앱 / 코치앱 / 관리자, 그리고 어느 화면
> 2. **무엇을 하려다** — 어떤 버튼을 누르셨는지
> 3. **무엇이 됐는지** — 기대하신 것과 실제로 일어난 일
>
> 원인이나 고치는 방법은 안 적으셔도 됩니다. 그건 저희가 찾습니다.
> 파일 이름 같은 것도 여쭤보지 않겠습니다.
>
> 대신 **"환불을 며칠까지 허용할까요" 처럼 규칙을 여쭤보면 꼭 답해주세요.**
> 그건 저희가 정하면 안 되는 것입니다.
>
> 급하면 **"지금 멈췄습니다"** 라고 먼저 알려주세요. 순서를 바꿔서 봅니다.
